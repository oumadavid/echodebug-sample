EchoDebug · 5 minutes

Hear the bug. Don’t just read it.

A voice-enabled debugging agent: paste a real build failure, get a spoken root-cause in the same terminal.

01 · Problem

Build logs are noisy. Time is not.

  • A failed next build dumps stack traces, module graphs, and red herrings.
  • The usual loop: copy the log → paste into chat → wait → read a wall of text.
  • Eyes stay on the error; the explanation should be heard, not dumped on screen.

02 · Solution

Identify the error. Read it aloud.

See

The original build error stays in the terminal. No spoken script printed on top of it.

Hear

Claude diagnoses the failure. ElevenLabs speaks the explanation in-session — no browser, no data-URL dump.

03 · How it runs

One pipe. One webhook. Voice back.

npm run build 2>&1 | node scripts/echodebug.js

terminal  →  n8n Cloud webhook
          →  Claude (root cause)
          →  ElevenLabs (speech)
          →  play MP3 here
